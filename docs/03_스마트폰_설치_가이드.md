# 스마트폰에 「순장학교」 앱 설치하기 — 처음 하시는 분용

> **결론** — 이 앱은 앱스토어에서 받지 않습니다. **인터넷 주소를 열고 → "홈 화면에 추가"를 누르면** 설치가 끝납니다. 걸리는 시간은 약 2분입니다.

---

| 궁금한 점 | 답 |
|---|---|

| 돈이 드나요? 회원가입이 필요한가요? | 무료입니다. 설치에는 가입이 필요 없습니다 (운영 시작 후 로그인은 이메일 인증코드로 합니다) |
| 어떤 앱으로 열어야 하나요? | **아이폰은 Safari(사파리)**, **안드로이드는 Chrome(크롬)** 또는 삼성 인터넷. **카카오톡 안에서 열면 설치가 안 됩니다** (아래 4장 참고) |

## 1단계. 앱 주소 살리기 — 관리자 1회만 (PC 권장, 약 1분)

> 이 단계는 **저장소 주인(관리자) 한 사람이 처음 한 번만** 합니다. 운영진은 2단계부터 하시면 됩니다.
> 쉽게 말해, 만들어 둔 앱을 인터넷에 "공개 버튼"을 눌러 여는 단계입니다.

| 순서 | 할 일 | 화면에서 찾는 법 |
|:-:|---|---|
| 1 | PC 브라우저에서 `github.com/76wooki-afk/soonjang-school-app` 접속 (로그인 상태) | 저장소 이름이 맨 위에 보이는 화면 |
| 2 | 위쪽 메뉴 줄의 **⚙ Settings** 클릭 | 메뉴 줄 맨 오른쪽 (Code · Issues · … · Settings) |
| 3 | 왼쪽 목록에서 **Pages** 클릭 | 왼쪽 목록 중간쯤 "Code and automation" 아래 |
| 4 | **Build and deployment → Source** 상자를 눌러 **GitHub Actions** 선택 | 선택하면 바로 저장됩니다 (저장 버튼 없음) |
| 5 | 위쪽 메뉴 **▶ Actions** 클릭 | Settings 왼쪽에 있음 |
| 6 | 왼쪽에서 **앱 배포 (GitHub Pages)** 클릭 → 오른쪽 **Run workflow** → 초록색 **Run workflow** | 회색 상자 안 버튼 |
| 7 | 1~2분 기다린 뒤 맨 위 줄에 **초록 ✓** 가 뜨면 완료 | 노란 점(●)은 "진행 중", 빨간 ✗는 "실패" |

**확인:** 휴대폰이나 PC에서 위 앱 주소를 열었을 때 파란 화면에 **"2026 순장학교 운영매뉴얼 대시보드"**가 보이면 성공입니다.

> 이전에 생긴 빨간 ✗ 기록 1건은 Pages를 켜기 전에 자동 실행된 것이라 무시하셔도 됩니다.

| 휴대폰 | 해당 | 이동 |
|---|---|---|
| 아이폰 (Apple) | 뒷면에 사과 로고 | **3-A** |

## 3-A. 아이폰에 설치하기 (Safari)

| 순서 | 할 일 | 설명 |
|:-:|---|---|
| 1 | 홈 화면에서 **나침반 모양 Safari** 앱을 엽니다 | 크롬·네이버 앱이 아닌 **Safari**여야 확실합니다 |
| 2 | 맨 위(또는 맨 아래) **주소창**을 한 번 누르고 앱 주소를 입력 → 키보드의 **이동** | 주소는 단톡방 링크를 길게 눌러 "복사" 후 붙여넣기 하면 편합니다 |
| 3 | 화면 아래쪽 **공유 버튼(□ 위로 화살표 ↑)**을 누릅니다 | 안 보이면 화면을 살짝 위로 밀거나, 주소창 옆 **⋯**을 누른 뒤 공유 |
| 4 | 나온 목록을 위로 밀어 **"홈 화면에 추가"**를 누릅니다 | 아이콘: 네모 안에 ＋ |
| 5 | 이름이 **"순장학교"**로 되어 있는지 확인 → 오른쪽 위 **추가** | 이름은 원하면 바꿔도 됩니다 |
| 6 | 홈 화면에 생긴 **네이비색 십자가·책 아이콘**을 눌러 실행 | 주소창 없이 전체 화면으로 열리면 성공 |

## 3-B. 안드로이드(갤럭시)에 설치하기

### Chrome(크롬)으로 설치 — 추천

| 순서 | 할 일 | 설명 |
|:-:|---|---|
| 1 | **Chrome**(빨강·노랑·초록 동그라미) 앱을 엽니다 | 없으면 Play 스토어에서 "Chrome" 설치 |
| 2 | 맨 위 주소창에 앱 주소 입력 → 이동 | |
| 3 | 화면 아래에 **"앱 설치"** 안내가 뜨면 바로 누르기. 안 뜨면 오른쪽 위 **⋮ (점 3개)** | |
| 4 | 메뉴에서 **"앱 설치"** 또는 **"홈 화면에 추가"** 선택 → **설치** | 휴대폰마다 문구가 조금 다릅니다 |
| 5 | 홈 화면(또는 앱 목록)에 생긴 **"순장학교"** 아이콘을 눌러 실행 | |

### 삼성 인터넷으로 설치

| 순서 | 할 일 |
|:-:|---|
| 1 | **삼성 인터넷**(보라색 행성 모양)에서 앱 주소 열기 |
| 2 | 아래쪽 **≡ (줄 3개)** → **＋ 페이지 추가** → **홈 화면** → **추가** |

## 4. 자주 막히는 곳 (문제 해결)

| 증상 | 원인 | 해결 |
|---|---|---|
| 카카오톡에서 링크를 눌렀더니 "홈 화면에 추가"가 없음 | 카카오톡 **안의** 브라우저로 열렸기 때문 | 카톡 화면 오른쪽 아래(또는 위) **⋮ / 공유 버튼 → "다른 브라우저로 열기"**(아이폰은 "Safari로 열기") 후 3단계 진행 |
| "404 There isn't a GitHub Pages site here" | 1단계(관리자 공개)가 아직 안 됨 | 관리자가 1단계 진행 후 2~3분 기다리기 |
| 아이콘을 눌렀는데 주소창이 보임 | 크롬이 아닌 다른 앱으로 "바로가기"만 만들어짐 | 아이콘 삭제 후 아이폰=Safari, 안드로이드=Chrome으로 다시 설치 |
| 화면이 하얗게만 나옴 | 인터넷 연결 불안정 | 와이파이/데이터 확인 후 앱을 완전히 닫았다 다시 열기 |
| 내용이 예전 그대로임 (업데이트 안 됨) | 휴대폰이 예전 화면을 기억 | 앱을 완전히 닫고(최근 앱 목록에서 위로 밀기) 다시 열기 |
| 아이콘을 지우고 싶음 | – | 아이콘을 길게 누르기 → **앱 제거/홈 화면에서 삭제**. 데이터는 구글 시트에 있어 지워지지 않습니다 |

## 5. 설치 후 처음 써 보기 (현재: 체험판)

지금은 실제 구글 시트와 연결하기 전 단계라 **가상 교육생 25명**으로 화면을 미리 보는 상태입니다.

| 해 볼 것 | 방법 |
|---|---|
| 역할별 화면 보기 | 위쪽 **접속 계정**에서 팀장·총무·테이블리더·교역자로 바꿔 보기 |
| 탭 이동 | 가운데 탭 줄(오늘 할 일 · 운영 현황 · Care …)을 **옆으로 밀어서** 선택 |
| 날짜 미리보기 | **기준일**이나 **시점 이동**에서 "1주차 D-Day" 등을 고르면 그날의 할 일이 보임 |

> 체험판에서 입력한 내용은 **그 휴대폰에만** 저장되며 다른 운영진에게 보이지 않습니다.
> 2단계(서버 연결) 이후에는 이메일 인증코드로 로그인하고, 입력 내용이 구글 시트에 저장되어 모든 운영진이 함께 봅니다. **앱을 다시 설치할 필요는 없습니다** — 같은 아이콘이 자동으로 새 버전으로 바뀝니다.

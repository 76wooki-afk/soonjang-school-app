# 1.5단계 결과 보고 — 원본 엑셀 대비 보강 (v4.2)

> **결론** — 원본 엑셀 비교에서 찾은 🔴 결함 2건과 🟠 누락 4건, 그리고 담당장로 역할을 개강 전에 반영했습니다. 서버 검증 25/25, 휴대폰 화면 검증 23/23을 통과했습니다. 기존 시트에는 **새 칸을 맨 끝에 추가만** 하므로, 이미 입력한 데이터는 그대로 유지됩니다.

## 1. 확정된 결정 (사용자 답변 반영)

| 항목 | 결정 | 앱 반영 |
|---|---|---|
| 개강일 | **2026-10-18(일)** | 1주차 10/18 → 수료예배 12/13 → 아웃팅 12/20 (기존과 동일) |
| 휴강 | 미정 | 설정 › **휴강일** 칸은 비워 둠. 나중에 입력하면 이후 주차가 자동으로 1주씩 밀림 |
| 회비 | **5만원 (가정)** | 설정 › **회비** 기본값 50,000원. 언제든 변경 가능 |
| 앱 사용자 | 팀장 · 총무 · 교역자 · **지정된 담당장로** | **담당장로(Elder) 역할** 신설, 테이블리더는 선택 사항으로 전환 |

## 2. 바뀐 점

| # | 등급 | 항목 | 이전 (v4.1.1) | 현재 (v4.2) |
|:-:|:-:|---|---|---|
| R1 | 🔴 | **예산** | 수입·지출 항목을 한 합계로 더함 → 집행률 오류 | **수입(교회예산·회비) / 지출** 구분. **수입 합계·지출 합계·잔액·수납률·집행률** 표시. 회비 줄은 **회비 × 등록 인원 / 납부 인원**으로 자동 계산 |
| R2 | 🔴 | **집결시간** | D-Day 체크·Staff 안내 문구 "집결 13:30" (큐시트는 14:30) | 설정 **'스텝 집결시간'(기본 14:30)** 신설 → D-Day 체크 시각, Run-of-Show 준비 시간, Staff D-1 안내 문구가 모두 이 값을 따름 |
| H1 | 🟠 | **회비** | 없음 | 교육생별 **'회비 납부' 체크**, 명단에 **납부 인원** 집계, 운영 현황에 **'회비 납부' 카드**(테이블리더에게는 미표시) |
| H2 | 🟠 | **개강 준비 체크** | 9개 | **11개**(+회비 결정, 과제 확인) + 항목별 **메모 칸** |
| H3 | 🟠 | **휴강** | 불가 (재계산 시 무조건 7일 간격) | 설정 › **휴강일** 입력 → 이후 주차가 1주씩 자동 연기, 주차 Board 상단에 휴강 표시 |
| H4 | 🟠 | **대표기도** | 대표기도 1칸 | 주차별 **담당공동체** 칸 (추천: 화평·믿음·소망·사랑·희락), Run-of-Show에도 표시 |
| 신설 | – | **담당장로 역할** | 없음 | **조회 전용** 6개 탭(오늘 할 일·운영 현황·Care·수료 관리·기수 캘린더·매뉴얼). Care 상세는 총무와 같이 가림. 매뉴얼 '담당장로' 줄에 이름 표시 |
| 신설 | – | 헬스체크 | T1~T5 테이블리더 필수 | 테이블리더 **선택 사항**으로 변경 |
| 추가 | 🟡 | **휴대폰 화면** (원본 문제) | 기수 캘린더·매뉴얼 탭의 상자가 화면 너비를 넘어(613px) 오른쪽이 잘림 | 화면 너비(354px)에 맞춤. 표는 상자 안에서 옆으로 밀어 봄 |

> 마지막 줄은 **원본(v4.1.1)에 원래 있던 휴대폰 화면 문제**입니다. 엑셀에는 없는 내용이지만 검증 중에 발견해 레이아웃 설정 한 줄로 고쳤습니다.

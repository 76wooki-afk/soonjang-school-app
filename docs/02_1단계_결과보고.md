## 5. 사용자께서 하실 일 — GitHub Pages 켜기 (1분)

GitHub Pages는 저장소의 `app/` 폴더를 **인터넷 주소로 공개해 주는 무료 기능**입니다.

| 순서 | 할 일 |
|---|---|
| 1 | 저장소 페이지 → 위쪽 메뉴 **Settings**(⚙ 설정) |
| 2 | 왼쪽 메뉴 **Pages** |
| 3 | **Build and deployment → Source** 를 **GitHub Actions** 로 선택 (저장 버튼 없음, 선택하면 끝) |
| 4 | 위쪽 메뉴 **Actions** → 왼쪽 **앱 배포 (GitHub Pages)** → 오른쪽 **Run workflow** → 초록 **Run workflow** |
| 5 | 1~2분 뒤 초록 ✓ 가 뜨면 앱 주소: **https://76wooki-afk.github.io/soonjang-school-app/** |

> 4번 전에 이미 빨간 ✗ 실패 기록이 하나 있을 수 있습니다. Pages를 켜기 전에 자동 실행된 기록이라 무시하셔도 됩니다.

## 6. 휴대폰에 설치해 보기

| 휴대폰 | 방법 |
|---|---|
| **아이폰** | Safari로 앱 주소 열기 → 아래 공유 버튼(□↑) → **홈 화면에 추가** → 추가 |
| **안드로이드** | Chrome으로 앱 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** (또는 홈 화면에 추가) |

설치 후 홈 화면의 **"순장학교"** 아이콘을 누르면 주소창 없이 전체화면으로 열립니다.

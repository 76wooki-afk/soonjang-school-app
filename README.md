# 순장학교 운영 앱

온누리교회 순장사관학교 운영진용 스마트폰 앱입니다. (교회 공식 앱 아님)
원본 **Operations OS v4.1.1**(구글 Apps Script 웹앱)의 화면·데이터·권한을 그대로 유지하고, 홈 화면에 설치하는 **앱(PWA)** 형태로 옮깁니다.

## 폴더 안내 (처음 보시는 분용)

| 폴더/파일 | 무엇인가요? | 직접 고칠 일 |
|---|---|---|
| `app/` | **휴대폰에 보이는 앱 화면**. 이 폴더가 그대로 인터넷 주소로 공개됩니다 | 거의 없음 |
| `app/index.html` | 원본 `Index.html`을 옮긴 앱 본체 (9개 탭) | – |
| `app/manifest.webmanifest` | 앱 이름·아이콘·색상 등 "설치 정보" | 앱 이름 바꿀 때 |
| `app/icons/` | 앱 아이콘 그림 | 아이콘 바꿀 때 |
| `server/` | 구글 Apps Script에 붙여 넣을 **서버 코드** (참고용 사본) | 시트 ID는 Apps Script에서만 입력 |
| `docs/` | 설계구상서·단계별 진행 보고 | – |
| `tests/` | 자동 검증 (서버 모의 실행 · 휴대폰 화면) | – |
| `.github/workflows/pages.yml` | `app/`이 바뀌면 자동으로 앱 주소에 반영하는 설정 | – |

## 진행 단계

| 단계 | 내용 | 상태 |
|---|---|:-:|
| 0 | 설계구상서 · 저장소 생성 | ✅ |
| 1 | 앱 골격 · 원본 화면 이식 · 아이콘 · 자동 배포 | ✅ |
| 1.5 | 원본 엑셀 대비 보강 (예산 수입/지출 · 집결시간 · 회비 · 휴강 · 대표기도 순번) — [검토보고](docs/04_원본엑셀_대비_검토보고.md) · [결과보고](docs/05_1.5단계_결과보고.md) | ✅ |
| 2 | 통신 어댑터 (앱 ↔ 구글 시트 연결) | ⏳ |
| 3 | 앱 완성도 (빠른 실행·오프라인 안내) | ⏳ |
| 4~7 | QA 연결 → UAT → 실운영 → 개강 | ⏳ |

## 개인정보 원칙

이 저장소는 **공개**입니다. 교육생·운영진 정보와 스프레드시트 ID는 이곳에 두지 않습니다.
실제 데이터는 구글 시트에만 있으며, 등록된 이메일과 인증코드로 로그인한 운영진에게만 보입니다.
